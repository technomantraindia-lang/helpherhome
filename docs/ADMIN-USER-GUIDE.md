# Helper Home Admin User Guide

## Daily workflow

1. Sign in with an active account.
2. Review dashboard counts and follow-ups.
3. Register workers, upload documents, complete verification, record interviews, and set availability.
4. Register customers and create one requirement per distinct need.
5. Use Worker Matching to review eligible workers, shortlist candidates, and create an assignment.
6. Confirm and start assignments. Use Replacement Requests when a replacement is needed.
7. Create an agreement from the assignment, review snapshots, capture signatures, generate the PDF, and share the controlled link.
8. Create invoices, record payments, and confirm receipts and outstanding balances.
9. Use Reports, CSV exports, Document Center, and Global Search for operations.
10. Review website enquiries, assign them, update status, schedule follow-ups, and convert qualified enquiries to customers and requirements.

## Enquiries

- Use **All Enquiries** for search and filters.
- Use **New**, **Follow-Ups**, **Converted**, and **Closed** quick filters.
- Call through the `tel:` action or open the prefilled WhatsApp message.
- Add a follow-up and mark it complete after contact.
- Conversion reuses a matching customer mobile number and creates a new requirement transactionally.

## Documents and security

- Use View/Download actions inside the admin portal.
- Do not copy private document paths into messages or public pages.
- Do not share passwords or exported sensitive data.
- Keep agency settings, users, and permissions restricted to authorized roles.
